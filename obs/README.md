# Автоматизация музыки через OBS Studio (Рекомендуемый подход)

Этот каталог содержит материалы для настройки автоматической паузы плеера **Kopuz** при воспроизведении заказов музыки прямо внутри OBS Studio (через Trula, StreamElements, DonationAlerts, Nightbot или любой Browser Source).

---

## Архитектура решения

```
[Зритель] ──► Заказ за баллы / донат (Trula, StreamElements и т.д.)
                    ↓
        [OBS Browser Source] (виджет плеера с галочкой «Управлять звуком»)
                    ↓
        [Advanced Scene Switcher] (следит за громкостью источника)
        ├── Появился звук (> -40 dB)      ──► Запуск: kopuzctl.exe pause
        └── Наступила тишина (> 3 сек)   ──► Запуск: kopuzctl.exe play
```

---

## Пошаговая настройка за 5 минут

### 1. Установка плагина в OBS
1. Скачайте и запустите установщик плагина **Advanced Scene Switcher**:
   👉 [https://github.com/WarmUpTill/SceneSwitcher/releases/latest](https://github.com/WarmUpTill/SceneSwitcher/releases/latest) (файл `advanced-scene-switcher-windows-x64-Installer.exe`).
2. Перезапустите OBS Studio. В верхнем меню появится: *Инструменты (Tools) ➔ Advanced Scene Switcher*.

### 2. Добавление источника заказа музыки в OBS
1. В нужной сцене OBS добавьте источник **«Браузер» (Browser Source)** и вставьте URL виджета заказов (например, из личного кабинета Trula или StreamElements).
2. Назовите источник понятно, например: `Музыка Заказ`.
3. **Обязательно:** в свойствах этого браузерного источника отметьте галочку **«Управлять звуком через OBS» (Control audio via OBS)**.
4. Откройте *Редактировать ➔ Расширенные свойства аудио (Advanced Audio Properties)*:
   Для источника `Музыка Заказ` в графе *«Прослушивание аудио» (Audio Monitoring)* выберите **«Мониторинг и вывод» (Monitor and Output)**.
   *Теперь звук заказа будет слышен и на стриме, и стримеру в наушниках.*

### 3. Настройка макросов в Advanced Scene Switcher
Откройте *Инструменты ➔ Advanced Scene Switcher ➔ вкладка «Macro»*.

#### Макрос 1: «Пауза Kopuz»
1. Нажмите **«+»** внизу списка макросов и введите имя: `Kopuz Pause`.
2. В блоке **Условия (Conditions)** нажмите «+»:
   - Тип: **Audio**
   - Источник: выберите ваш браузерный источник (`Музыка Заказ`)
   - Условие: **Output volume is above**
   - Порог: **-40 dB**
3. В блоке **Действия (Actions)** нажмите «+»:
   - Тип: **Run**
   - File / Command: путь к `kopuzctl.exe` (например, `C:/Program Files/Kopuz/kopuzctl.exe` или просто `kopuzctl`, если добавлен в PATH)
   - Arguments: `pause`

#### Макрос 2: «Возобновление Kopuz»
1. Нажмите **«+»** и создайте макрос: `Kopuz Resume`.
2. В блоке **Условия (Conditions)** нажмите «+»:
   - Тип: **Audio**
   - Источник: `Музыка Заказ`
   - Условие: **Output volume is below**
   - Порог: **-45 dB**
   - Отметьте опцию **«for at least»**: укажите **3 секунды** (чтобы секундная пауза внутри трека случайно не включила фоновую музыку).
3. В блоке **Действия (Actions)** нажмите «+»:
   - Тип: **Run**
   - File / Command: путь к `kopuzctl.exe`
   - Arguments: `play`

### 4. Включение автоматизации
1. На вкладке **General** плагина Advanced Scene Switcher нажмите **Start**, чтобы плагин стал активен (Status: Running).
2. Включите галочку **«Start automatically»**, чтобы плагин автоматически запускался при старте OBS.

---

## Проверка
1. Запустите Kopuz и включите фоновую музыку.
2. В панели сервиса заказов воспроизведите тестовый трек.
3. Как только в источнике появится звук — Kopuz моментально встанет на паузу.
4. Когда трек доиграет и пройдёт 3 секунды тишины — Kopuz возобновит воспроизведение с той же секунды.
