# Twitch Music Bot

Бот для заказов музыки через баллы канала Twitch. Когда зритель заказывает трек, бот ставит локальную музыку в **Kopuz** на паузу, проигрывает заказанный YouTube-трек через headless **mpv** (без окна, только звук), а по окончании возвращает Kopuz с той же секунды.

Русский интерфейс наград и сообщений, английский код.

## Принцип работы

```
Зритель жмёт награду в чате Twitch
        ↓
EventSub WebSocket уведомляет бота
        ↓
Бот проверяет лимиты → извлекает аудио YouTube через yt-dlp
        ↓
Бот ставит Kopuz на паузу (kopuzctl pause)
        ↓
mpv проигрывает трек (без окна, только звук)
        ↓
Трек закончился → бот возвращает Kopuz с паузы (kopuzctl play)
```

В каждый момент времени звучит **ровно одно** приложение — либо Kopuz, либо mpv. В OBS ничего дополнительно настраивать не нужно: он захватывает обычный системный звук (Desktop Audio).

## Что нужно установить

На ПК стримера (Windows):

1. **Python 3.11+** — с [python.org](https://www.python.org/). При установке обязательно включите галочку *"Add Python to PATH"*.
2. **Зависимости Python** — в командной строке выполните:
   ```cmd
   pip install websockets httpx
   ```
3. **mpv** — portable-сборка с [mpv.io](https://mpv.io/installation/) (или через `winget install mpv`). Положите `mpv.exe` в удобную папку, например `C:\tools\mpv.exe`.
4. **yt-dlp** — свежий релиз с [github.com/yt-dlp/yt-dlp/releases](https://github.com/yt-dlp/yt-dlp/releases). Положите `yt-dlp.exe` рядом, например `C:\tools\yt-dlp.exe`.
5. **Kopuz** — должен быть установлен и запущен с вашей локальной библиотекой. Утилита `kopuzctl` идёт в комплекте с Kopuz.
6. **Этот репозиторий** — склонируйте или скачайте архив.

Проверьте доступность инструментов в терминале:
```cmd
mpv --version
yt-dlp --version
kopuzctl --version
```

## Регистрация приложения Twitch

Боту нужны свои учётные данные Twitch API (Client ID + Client Secret).

1. Включите **двухфакторную аутентификацию (2FA)** на своём аккаунте Twitch (обязательно для разработчиков Twitch).
2. Перейдите в [Twitch Developer Console](https://dev.twitch.tv/console).
3. Вкладка **Applications** → **Register Your Application**.
4. Заполните:
   - **Name:** `Twitch Music Bot` (или любое уникальное имя)
   - **OAuth Redirect URLs:** `http://localhost:3000` (нужно для регистрации в панели; бот не требует поднятия веб-сервера)
   - **Category:** `Chat Bot`
5. Нажмите **Create**.
6. В списке приложений нажмите **Manage** напротив созданного приложения.
7. Скопируйте **Client ID**.
8. Нажмите **New Secret** и скопируйте **Client Secret** (секрет показывается только один раз).

## Настройка config.json

Скопируйте `config.example.json` в `config.json` и отредактируйте:

```json
{
  "twitch": {
    "client_id": "ВАШ_CLIENT_ID",
    "client_secret": "ВАШ_CLIENT_SECRET",
    "broadcaster_user_id": "123456789",
    "scopes": "channel:read:redemptions channel:manage:redemptions user:write:chat",
    "token_file": "tokens.json"
  },
  "paths": {
    "mpv": "C:/tools/mpv.exe",
    "yt_dlp": "C:/tools/yt-dlp.exe",
    "kopuzctl": "C:/Program Files/Kopuz/kopuzctl.exe",
    "state_dir": "./state",
    "log_file": "./bot.log"
  },
  "reward": {
    "title": "Заказ музыки",
    "cost": 500,
    "background_color": "#9147FF",
    "is_user_input_required": true,
    "prompt": "Ссылка на YouTube-трек",
    "max_per_stream": 0,
    "max_per_user_per_stream": 0,
    "global_cooldown_seconds": 0,
    "should_redemptions_skip_request_queue": false
  },
  "limits": {
    "max_track_seconds": 360,
    "max_queue_size": 20,
    "max_per_user": 2,
    "user_cooldown_seconds": 60,
    "resume_debounce_seconds": 2.0,
    "yt_dlp_timeout_seconds": 20,
    "mpv_timeout_seconds": 0
  },
  "behavior": {
    "pause_kopuz_during_request": true,
    "announce_in_chat": true,
    "auto_refund_on_error": true,
    "youtube_links_only": true
  }
}
```

### broadcaster_user_id (числовой ID канала)

Укажите ваш числовой ID пользователя Twitch (например `123456789`, а не никнейм). Узнать свой ID можно через любой сервис вроде [twitchtokengenerator.com/tools/user-id-from-url](https://www.twitchtokengenerator.com/tools/user-id-from-url).

### Поддерживаемые форматы ссылок YouTube

Зрители могут отправлять прямые ссылки на YouTube в любом виде:
- Обычные ссылки: `https://www.youtube.com/watch?v=...` или `https://youtube.com/watch?v=...`
- Ссылки с мобильных: `https://m.youtube.com/watch?v=...`
- Музыкальный YouTube: `https://music.youtube.com/watch?v=...`
- Короткие ссылки: `https://youtu.be/...`
- YouTube Shorts: `https://www.youtube.com/shorts/...`
- Ссылки с таймкодами и параметрами в любом порядке. Бот нормализует ссылку и очищает её от лишних списков воспроизведения (`&list=...`).

### Все лимиты настраиваются пользователем

В секции `"limits"` вы можете в любой момент изменить:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `max_track_seconds` | 360 | Макс. длительность заказанного трека в секундах (0 = без ограничений) |
| `max_queue_size` | 20 | Макс. число треков в очереди одновременно (0 = без ограничений) |
| `max_per_user` | 2 | Сколько треков от одного зрителя может находиться в очереди |
| `user_cooldown_seconds` | 60 | Пауза между заказами от одного зрителя в секундах |
| `resume_debounce_seconds` | 2.0 | Пауза перед включением Kopuz после опустения очереди (склейка треков) |

Изменения вступают в силу после перезапуска бота.

## Первый запуск и авторизация

В папке с ботом откройте терминал и выполните:

```cmd
python -m twitch_musicbot
```

При первом запуске бот определит отсутствие файла `tokens.json` и начнёт **Device Code Flow**:

1. В консоли появится ссылка `https://www.twitch.tv/activate` и 8-значный код.
2. Откройте ссылку в браузере и введите код.
3. Подтвердите авторизацию от имени стрим-аккаунта (чей `broadcaster_user_id` указан в конфиге).
4. Бот автоматически сохранит токены в `tokens.json` и начнёт работу.

При последующих запусках авторизация не требуется — бот сам обновляет токены через `refresh_token`. Refresh-токен становится недействительным только после 30 дней полного простоя.

## Награду в Twitch создаёт сам бот

**Важно:** Не создавайте награду вручную через панель Twitch! При первом запуске бот сам создаёт награду «Заказ музыки» с настройками из `config.json`.

**Почему:** Twitch разрешает отменять заказы и возвращать баллы только тому приложению, которое создало эту награду. Если награду создать вручную через сайт, бот не сможет автоматически вернуть баллы зрителю при недоступном видео.

Убедитесь в настройках Twitch, что созданная награда **включена** (is_enabled = true).

## Проверка перед стримом

1. Убедитесь, что **Kopuz запущен** и воспроизводит музыку из вашей библиотеки.
2. Запустите бота (`python -m twitch_musicbot`). В консоли появится: `✓ Бот успешно запущен и ожидает заказов.`
3. Сделайте тестовый заказ за баллы, указав любую ссылку на YouTube.
4. Проверьте:
   - Kopuz встал на паузу.
   - В эфир/наушники пошёл звук из mpv (без всплывающих окон).
   - По окончании трека Kopuz возобновил воспроизведение ровно с той же секунды.
   - В чат пришло оповещение о воспроизведении.

## Запуск как фоновый процесс (Windows)

Чтобы бот запускался автоматически при включении ПК и работал в фоне:

1. Откройте «Планировщик заданий» Windows (`taskschd.msc`) → «Создать простую задачу».
2. Имя: `Twitch Music Bot`.
3. Триггер: «При входе в систему».
4. Действие: «Запустить программу».
   - Программа: `python.exe` (полный путь, например `C:\Users\Имя\AppData\Local\Programs\Python\Python311\python.exe`)
   - Аргументы: `-m twitch_musicbot`
   - Рабочая папка: папка с ботом (например `C:\tools\twitch-musicbot`)

Или запускайте обычным `.bat` скриптом:

```bat
@echo off
cd /d C:\tools\twitch-musicbot
python -m twitch_musicbot
pause
```

## Лимиты — где менять

Все параметры находятся в `config.json`:

```json
"limits": { ... }    <- количество, время, размеры очереди, кулдауны
"reward": { ... }    <- название, цена в баллах, цвет награды
"behavior": { ... }  <- пауза Kopuz, сообщения в чат, авто-возврат баллов
"paths": { ... }     <- пути к mpv, yt-dlp, kopuzctl
```

После редактирования `config.json` просто перезапустите бота.

## Что если что-то сломалось

| Проблема | Причина и решение |
|---|---|
| `mpv не найден` или `yt-dlp не найден` | Проверьте пути в секции `"paths"` в `config.json`. Рекомендуется указывать абсолютные пути через прямой слэш (например `C:/tools/mpv.exe`). |
| Kopuz не ставится на паузу | Убедитесь, что приложение Kopuz открыто и играет. Версия `kopuzctl` должна строго совпадать с версией установленного Kopuz. |
| Заказ принят, но баллы не возвращаются | Убедитесь, что награда создана ботом, а `broadcaster_user_id` соответствует аккаунту стримера. |
| Ошибка воспроизведения трека YouTube | Обновите `yt-dlp` командой `yt-dlp -U`. YouTube периодически обновляет свои алгоритмы. Баллы при сбое возвращаются зрителю автоматически. |
| Оба плеера играют одновременно | Если бот был экстренно закрыт во время трека, при следующем запуске он автоматически снимет паузу с Kopuz (механизм fail-open). |
| Звук трека не слышен на стриме | Проверьте, чтобы в OBS был включён захват системного звука (Desktop Audio). |
