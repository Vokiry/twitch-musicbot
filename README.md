# Twitch Music Bot

Бот для заказов музыки через баллы канала Twitch. Когда зритель заказывает трек, бот ставит локальную музыку в **Kopuz** на паузу, проигрывает заказанный YouTube-трек через headless **mpv** (без окна), а по окончании возвращает Kopuz с той же секунды.

Русский интерфейс наград и сообщений, английский код.

## Принцип работы

```
Зритель жмёт награду в чате Twitch
        ↓
EventSub WebSocket уведомляет бота
        ↓
Бот проверяет лимиты → извлекает аудио YouTube через yt-dlp
        ↓
Бот ставит Kopuz на паузу (kopuzctl pause)
        ↓
mpv проигрывает трек (без окна, только звук)
        ↓
Трек закончился → бот возвращает Kopuz с паузы (kopuzctl play)
```

В каждый момент времени звучит **ровно одно** приложение — либо Kopuz, либо mpv. OBS ничего特別 настраивать не нужно: он捕获ляет обычный системный звук.

## Что нужно установить

На ПК стримера (Windows):

1. **Python 3.11+** — с [python.org](https://www.python.org/). При установке галочка *"Add Python to PATH"*.
2. **mpv** — portable сборка с [mpv.io](https://mpv.io/installation/) (или через `winget install mpv`). Положите `mpv.exe` в любую папку, например `C:\tools\mpv.exe`.
3. **yt-dlp** — с [github.com/yt-dlp/yt-dlp/releases](https://github.com/yt-dlp/yt-dlp/releases). Положите `yt-dlp.exe` рядом, например `C:\tools\yt-dlp.exe`.
4. **Kopuz** — должен быть установлен и запущен с вашей локальной библиотекой. `kopuzctl` идёт в комплекте с Kopuz.
5. **Этот репозиторий** — склонируйте или скачайте ZIP.

Проверьте в командной строке:
```cmd
mpv --version
yt-dlp --version
kopuzctl --version
```

## Регистрация приложения Twitch

Боту нужны свои учётные данные Twitch API (Client ID + Client Secret).

1. Включите **двухфакторную аутентификацию (2FA)** на своём аккаунте Twitch (обязательно, иначе не создастся приложение).
2. Перейдите на [https://dev.twitch.tv/console](https://dev.twitch.tv/console).
3. Вкладка **Applications** → **Register Your Application**.
4. Заполните:
   - **Name:** `Twitch Music Bot` (или любое уникальное имя)
   - **OAuth Redirect URLs:** `http://localhost:3000` (нужно для регистрации, бот не использует веб-сервер)
   - **Category:** `Chat Bot`
5. Нажмите **Create**.
6. Во вкладке **Manage** скопируйте **Client ID**.
7. Нажмите **New Secret**, скопируйте **Client Secret** (показывается один раз).

## Настройка config.json

Скопируйте `config.example.json` в `config.json` и отредактируйте:

```json
{
  "twitch": {
    "client_id": "ВАШ_CLIENT_ID",
    "client_secret": "ВАШ_CLIENT_SECRET",
    "broadcaster_user_id": "123456789",
    "token_file": "tokens.json"
  },
  "paths": {
    "mpv": "C:/tools/mpv.exe",
    "yt_dlp": "C:/tools/yt-dlp.exe",
    "kopuzctl": "C:/Program Files/Kopuz/kopuzctl.exe",
    "state_dir": "./state",
    "log_file": "./bot.log"
  },
  "reward": {
    "title": "Заказ музыки",
    "cost": 500,
    "background_color": "#9147FF",
    "is_user_input_required": true,
    "prompt": "Ссылка на YouTube-трек",
    "max_per_stream": 0,
    "max_per_user_per_stream": 0,
    "global_cooldown_seconds": 0,
    "should_redemptions_skip_request_queue": false
  },
  "limits": {
    "max_track_seconds": 360,
    "max_queue_size": 20,
    "max_per_user": 2,
    "user_cooldown_seconds": 60,
    "resume_debounce_seconds": 2.0,
    "yt_dlp_timeout_seconds": 20,
    "mpv_timeout_seconds": 0
  },
  "behavior": {
    "pause_kopuz_during_request": true,
    "announce_in_chat": true,
    "auto_refund_on_error": true,
    "youtube_links_only": true
  }
}
```

### broker_user_id (числовой ID канала)

Зайдите на [https://api.twitch.tv/helix/users?login=ВАШ_ЛОГИН](https://api.twitch.tv/helix/users?login=ВАШ_ЛОГИН) (нужен Client-ID заголовок) или проще: используйте сторонние сервисы вроде [twitchtokengenerator.com](https://www.twitchtokengenerator.com/tools/user-id-from-url) чтобы узнать числовой ID своего канала.

### Все лимиты настраиваются пользователем

В секции `[limits]` вы можете в любой момент изменить:

| Параметр | Значение по умолчанию | Что означает |
|---|---|---|
| `max_track_seconds` | 360 | Макс. длительность заказанного трека (0 = без ограничения) |
| `max_queue_size` | 20 | Макс. треков в очереди одновременно (0 = без ограничения) |
| `max_per_user` | 2 | Сколько треков от одного зрителя может быть в очереди |
| `user_cooldown_seconds` | 60 | Пауза между заказами одного зрителя |
| `resume_debounce_seconds` | 2.0 | Задержка перед возобновлением Kopuz после конца очереди |

Изменения вступают в силу после перезапуска бота.

## Первый запуск и авторизация

В папке с ботом откройте терминал и выполните:

```cmd
python -m twitch_musicbot
```

В первый раз бот не найдёт `tokens.json` и запустит **Device Code Flow**:

1. В консоли появится код и ссылка `https://www.twitch.tv/activate?public=true&device-code=XXXX`.
2. Откройте ссылку в браузере, введите код.
3. Авторизуйте бота от имени стрим-аккаунта (тот же аккаунт, чей `broadcaster_user_id` в конфиге).
4. Бот сохранит токены в `tokens.json` и продолжит работу.

При последующих запусках токены подгружаются автоматически. Если они истекут — бот обновит их сам (refresh token). Refresh token одноразовый и становится недействительным через 30 дней бездействия — тогда нужно будет заново пройти Device Code Flow.

## Награду в Twitch создаёт сам бот

Не создавайте награду вручную в панели Twitch! Бот при первом запуске сам создаёт награду "Заказ музыки" с указанной стоимостью.

**Почему:** Twitch позволяет возвращать баллы и менять статус заказа только приложению, которое создало награду. Если создать награду вручную, бот не сможет вернуть баллы при ошибке.

Награда появится в разделе "За библиотекой баллов канала" у зрителей. Убедитесь, что она **включена** (enabled) и не на паузе.

## Проверка перед стримом

1. Убедитесь, что **Kopuz запущен** и играет вашу библиотеку.
2. Запустите бота. В логе должно быть `Бот готов. Ожидаю заказы...`.
3. Попросите moderator или себя затестить награду: вставьте любую ссылку на YouTube.
4. Проверьте:
   - Kopuz встал на паузу.
   - В наушниках/стриме пошёл звук из mpv.
   - По окончании трека Kopuz продолжил с того же места.
   - В чат пришло сообщение "Сейчас играет...".

Если Kopuz **не встал на паузу** — проверьте путь к `kopuzctl` в конфиге и что Kopuz открыт (на Windows `kopuzctl` подключается к запущенному приложению Kopuz).

## Запуск как фоновый процесс (Windows)

Чтобы бот стартовал вместе с системой и не требовал открытого окна терминала, используйте **Планировщик заданий**:

1. Откройте "Планировщик заданий" → "Создать простую задачу".
2. Имя: `Twitch Music Bot`.
3. Триггер: "При входе в систему".
4. Действие: "Запустить программу".
   - Программа: `python.exe` (полный путь, например `C:\Python311\python.exe`)
   - Аргументы: `-m twitch_musicbot`
   - Начать в: папка с репозиторием бота (например `C:\Users\You\twitch-musicbot`)
5. Установите флаг "Запускать независимо от входа в систему" — не нужно, достаточно при входе.

Альтернативно — просто запускайте `.bat` файл перед стримом:

```bat
@echo off
cd /d C:\path\to\twitch-musicbot
python -m twitch_musicbot
pause
```

## Лимиты — где менять

Все настраиваемые лимиты находятся в `config.json`:

```ini
[limits]          <- количество, время, размеры очереди
[reward]          <- цена награды, текст, цвет, кулдауны Twitch
[behavior]        <- пауза Kopuz, сообщения в чат, авто-возврат баллов
[paths]           <- пути к mpv, yt-dlp, kopuzctl
```

После правки **перезапустите бота**.

## Что если что-то сломалось

| Проблема | Решение |
|---|---|
| Бот не находит `mpv` / `yt-dlp` / `kopuzctl` | Проверьте пути в `[paths]`, используйте абсолютные пути (`C:/tools/mpv.exe`) |
| Kopuz не ставится на паузу | Убедитесь, что Kopuz запущен; версия `kopuzctl` совпадает с версией приложения |
| Заказ не проходит, баллы не возвращаются | Проверьте `broadcaster_user_id`, что бот авторизован и reward создан ботом |
| Трек не играет (YouTube) | Обновите `yt-dlp`: `yt-dlp -U`. YouTube часто меняет разметку. |
| Бот работал, а потом перестал | Проверьте `tokens.json` — refresh token истекает через 30 дней бездействия, пройдите авторизацию заново |
| Оба играют одновременно (Kopuz + mpv) | Бот упал во время паузы. Перезапустите бота — он снимет паузу с Kopuz (fail-open). |
| Звук запроса не попадает в стрим | Убедитесь, что OBS захватывает **Desktop Audio**, а не только конкретное приложение. |
