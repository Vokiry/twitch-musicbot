# Twitch Music Stack: Управление фоновой музыкой и заказами треков

Проект решает ключевую задачу стримера: **локальная фоновая музыка (в плеере Kopuz) автоматически встаёт на паузу во время воспроизведения заказанного трека и возобновляется с той же секунды после его окончания**.

В репозитории представлены два взаимодополняющих решения:
1. 🌟 **Основное production-решение для стримера (без кода, через OBS):** Самый надёжный, лёгкий и естественный для стримера путь — плеер заказов крутится внутри OBS (через Trula, DonationAlerts, StreamElements или Nightbot), а плагин автоматизации отслеживает уровень звука и переключает паузу в Kopuz.
2. 🛠️ **Автономный Python-стек (для разработчиков):** Модули собственного бота (Twitch Device Code Flow, EventSub WebSocket, Helix REST API, нормализация YouTube-ссылок, очередь и контроллер `kopuzctl`), спроектированные для переиспользования в других проектах стримерского окружения.

## Часть 1. Пошаговый гайд для стримера (Рекомендуемое решение)

> **Преимущества:** 0 строк кода, никаких токенов и консолей разработчика Twitch, видеоклип отображается на стриме, громкость регулируется прямо в микшере OBS, защита от банов YouTube.

### Схема работы

```
Зритель заказывает трек за баллы или донат (Trula / StreamElements / др.)
                    ↓
        Виджет плеера играет в OBS (Browser Source)
                    ↓
        Плагин Advanced Scene Switcher видит уровень звука:
        ├── Появился звук (> -40 dB)      ──► kopuzctl.exe pause
        └── Наступила тишина (> 3 сек)   ──► kopuzctl.exe play
```

### Пошаговая инструкция (настройка за 5 минут)

#### Шаг 1. Подготовка плеера и плагина
1. Убедитесь, что **Kopuz** установлен и играет вашу локальную библиотеку. Утилита `kopuzctl.exe` идёт в комплекте с плеером.
2. Установите плагин **Advanced Scene Switcher** для OBS Studio:
   - Скачайте установщик со страницы релизов: [Advanced Scene Switcher Releases](https://github.com/WarmUpTill/SceneSwitcher/releases/latest) (файл `advanced-scene-switcher-windows-x64-Installer.exe`).
   - Запустите установку и перезапустите OBS Studio.
   - В верхнем меню OBS появится пункт: *Инструменты ➔ Advanced Scene Switcher*.

#### Шаг 2. Добавление виджета заказов в OBS
1. В сцену OBS добавьте источник **«Браузер» (Browser Source)** и вставьте URL виджета плеера (из Trula, StreamElements или любого другого сервиса заказов).
2. Назовите источник, например: `Заказ музыки`.
3. **Критически важная настройка:** В свойствах источника обязательно включите галочку **«Управлять звуком через OBS»** (*Control audio via OBS*).
   *После этого полоска громкости заказа появится в «Микшере аудио» OBS.*
4. Откройте меню *Редактировать ➔ Расширенные свойства аудио*:
   - Найдите источник `Заказ музыки`.
   - В колонке *«Прослушивание аудио» (Audio Monitoring)* выберите **«Мониторинг и вывод»** (*Monitor and Output*).
   - Теперь заказанный трек слышите и вы в наушниках, и зрители на трансляции.

#### Шаг 3. Настройка макросов паузы и возобновления
Откройте *Инструменты ➔ Advanced Scene Switcher ➔ вкладка «Macro»*.

**Макрос 1: «Пауза при старте заказа»**
1. Нажмите **«+»** под списком макросов, введите имя: `Kopuz Pause`.
2. В секции **Условия (Conditions)** нажмите «+»:
   - Тип: **Audio**
   - Источник: выберите `Заказ музыки`
   - Условие: **Output volume is above**
   - Порог: **-40 dB**
3. В секции **Действия (Actions)** нажмите «+»:
   - Тип: **Run**
   - File: полный путь к `kopuzctl.exe` (например, `C:/Program Files/Kopuz/kopuzctl.exe`)
   - Arguments: `pause`

**Макрос 2: «Возобновление после окончания заказа»**
1. Нажмите **«+»** и создайте второй макрос: `Kopuz Resume`.
2. В секции **Условия (Conditions)** нажмите «+»:
   - Тип: **Audio**
   - Источник: `Заказ музыки`
   - Условие: **Output volume is below**
   - Порог: **-45 dB**
   - Отметьте опцию **«for at least»** и укажите **3 секунды** (порог склейки, чтобы секундные паузы внутри трека случайно не включали фон).
3. В секции **Действия (Actions)** нажмите «+»:
   - Тип: **Run**
   - File: путь к `kopuzctl.exe`
   - Arguments: `play`

#### Шаг 4. Включение плагина
1. Перейдите на вкладку **General** в окне Advanced Scene Switcher.
2. Нажмите кнопку **Start** (статус сменится на *Running*).
3. Включите галочку **«Start automatically»**, чтобы автоматизация запускалась сама вместе с OBS.

#### Шаг 5. Проверка работы
1. Включите музыку в Kopuz.
2. Запустите любой тестовый заказ в Trula / панели заказов.
3. При появлении звука заказа Kopuz сразу встанет на паузу.
4. По окончании трека и истечении 3 секунд тишины Kopuz продолжит играть ровно с того же места.

Подробная памятка по OBS также доступна в папке [`obs/README.md`](obs/README.md).

## Часть 2. Модули Python для других проектов (Архитектура бота)

Если вы разрабатываете собственного комплексного Twitch-бота или расширяете стримерское окружение, в этом репозитории реализованы независимые, строго протестированные модули, готовые к переиспользованию:

```
src/twitch_musicbot/
├── auth.py        # Авторизация Twitch Device Code Flow + авто-ротация токенов
├── eventsub.py    # Клиент WebSocket Twitch EventSub (полная спецификация)
├── api.py         # Twitch Helix REST API (награды, редемпшены, чат, подписки)
├── player.py      # Парсер/нормализатор YouTube-ссылок и запуск headless mpv
├── kopuz.py       # Отказоустойчивый контроллер плеера Kopuz
├── queue.py       # Потокобезопасная очередь с кулдаунами и дедупликацией
├── config.py      # Управление конфигурацией (JSON) с дефолтами
├── state.py       # Сохранение состояния паузы (fail-open при сбоях)
└── chat.py        # Неблокирующий анонсер сообщений в чат Twitch
```

### 1. `auth.py` — Авторизация без локального веб-сервера (Device Code Flow)
- Позволяет десктопным скриптам авторизоваться на Twitch через `https://www.twitch.tv/activate` без поднятия веб-серверов и проброса портов.
- Поддерживает опрос статуса с корректной обработкой `authorization_pending` и `slow_down`.
- Автоматически обновляет токен через `refresh_token` при истечении срока действия (4 часа) и сохраняет состояние на диск.

### 2. `eventsub.py` — Twitch EventSub WebSocket клиент
- Подключается к `wss://eventsub.wss.twitch.tv/ws`.
- Строго соблюдает протокол: не отправляет текстовых фреймов в сокет (что запрещено Twitch и вызывало ошибку `4001: Client sent inbound traffic`).
- Поддерживает миграцию сервера через `session_reconnect` с переходом на `reconnect_url`.

### 3. `api.py` — Twitch Helix REST клиент
- Регистрация EventSub-подписок (`POST /helix/eventsub/subscriptions`) с привязкой к `session_id`.
- Управление наградами за баллы канала (`GET` и `POST /helix/channel_points/custom_rewards`).
- Обновление статусов заказов (`PATCH /helix/channel_points/custom_rewards/redemptions` ➔ `FULFILLED` или `CANCELED` для возврата баллов).
- Отправка сообщений в чат (`POST /helix/chat/messages`).

### 4. `player.py` — Нормализация YouTube-ссылок и headless-плеер
- Функция `extract_youtube_video_id` надёжно извлекает 11-значный ID видео из любых форматов:
  - `youtube.com/watch?v=...`, мобильных `m.youtube.com`, `music.youtube.com`
  - Коротких `youtu.be/...`, `youtube.com/shorts/...`, `/embed/`, `/v/`
  - Ссылок с любым порядком параметров (например, `?feature=shared&v=...`).
- Автоматически очищает ссылки от плейлистов (`&list=...`), предотвращая скачивание сотен чужих треков.
- Запуск `mpv` передаёт точный путь к `yt-dlp` через `--script-opts=ytdl_hook-ytdl_path=...` и скрывает консольные окна на Windows (`CREATE_NO_WINDOW`).

### 5. `queue.py` — Очередь с защитой от спама
- Лимит треков на одного зрителя (`max_per_user`).
- Персональный кулдаун между заказами (`user_cooldown_seconds`).
- Скользящее окно дедупликации (30 минут): трек нельзя заказать повторно сразу, но запись автоматически очищается по истечении времени.
- Сохранение и восстановление очереди на диск в JSON.

### 6. `kopuz.py` — Контроллер Kopuz
- Защита от `FileNotFoundError`: если путь к `kopuzctl` не задан или утилита недоступна, бот логирует понятное предупреждение, а не падает с трейсбеком.
- Вызовы `pause`, `play`, `status --json` и проверка фазы воспроизведения.

## Тестирование модулей

Все модули покрыты тестами на базе стандартной библиотеки `unittest` (не требуют установки сторонних пакетов для запуска):

```cmd
python -m unittest discover -s tests -v
```

Тестовый набор включает 18 тестов:
- Парсинг всех вариаций YouTube-ссылок и отсечение невалидных URL (`tests/test_url.py`).
- Логика очереди, лимиты, кулдауны, очистка дедупликатора и сохранение (`tests/test_queue.py`).
- Загрузка, слияние дефолтов и обработка пустых файлов конфигурации (`tests/test_config.py`).

## Быстрый запуск автономного бота (если нужен Python)

1. Установите зависимости:
   ```cmd
   pip install websockets httpx
   ```
2. Скопируйте `config.example.json` в `config.json` и укажите данные приложения Twitch.
3. Запустите бота:
   ```cmd
   python -m twitch_musicbot
   ```
